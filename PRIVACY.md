# Privacy Policy — prominence-chan

Last updated: November 25, 2026

This Privacy Policy explains what data the **prominence-chan** Discord application ("the Bot") accesses and stores when used in Discord servers or direct messages.

## 1. Data We Access and Store
- **Recent channel context:** To generate relevant replies in channels where the Bot is active, the Bot reads recent message content, author display names/IDs, timestamps, and attachments in those channels.
- **Configuration and state:** Server settings, command permissions, opt-out preferences, and scheduled reminders configured by authorized users.
- **Logs:** Basic operational logs (such as error diagnostics and command usage) used solely to maintain and debug the Bot.

## 2. How Data Is Used
- Data is used strictly to provide the Bot's conversational, utility, and moderation features.
- Message context may be processed by third-party AI model providers solely to generate responses when the Bot is invoked.
- We do **not** sell user data or use it for advertising.

## 3. Opt-Out and Data Deletion
- Users may opt out of having the Bot respond to them or process their messages where opt-out commands are enabled, and server administrators may remove the Bot from a server at any time.
- To request deletion of stored data associated with your Discord user ID or server ID, please open an issue at https://github.com/prominence-chan/prominence-chan/issues.

## 4. Data Retention and Security
- Stored state and logs are kept only as long as needed for the Bot's operation and troubleshooting.
- Reasonable technical measures are used to restrict access to stored data.

## 5. Changes to This Policy
- This Privacy Policy may be updated from time to time; the latest version is always published at this URL.
